# Google 搜索守护（个人版）1.0.0

## 首次安装

1. 完整解压，把本文件所在的 `EdgeGooglePersonal` 文件夹放到长期保留、当前用户可写的位置，例如自己的 Documents。不要在 ZIP 中直接运行，安装后不要移动或删除此目录。
2. 在 Edge 中切换到目标配置文件，再以普通用户权限双击本目录的 `Install.cmd`。脚本选择 Edge 最近使用的配置文件，请核对其输出。
3. 在同一配置文件的 Edge 地址栏手动输入 `edge://extensions/`。打开“开发人员模式”，选择“加载解压缩的扩展”，加载本目录下的 `Extension` 子目录。
4. 如 Edge 询问，确认启用扩展及其 Google 搜索设置。
5. 打开扩展弹窗，等待“已验证：默认搜索请求发往 Google”和绿色 `OK`。Edge 运行时通常约一分钟内检查。

要求 Windows、Windows PowerShell 5.1 和允许加载解压缩扩展的 Edge 配置文件。安装与日常运行不需要 Node.js 或 Python。已有相同 ID 扩展的使用者不应直接重新安装或移动原目录。

## 使用与排查

- `Verify.cmd`：发出新的本地请求。实际结果看扩展弹窗，并核对 `requestId`、`checkedAt`。
- `Check.cmd`：检查任务和磁盘状态。`Pending`、`present-not-live-verified`、任务退出码 `0` 均不是实际搜索成功的证据。
- `Install.cmd`：注册登录任务，会重新选择 Edge 最近使用的配置文件，不要作为例行检查使用。
- 登录后 20 秒触发任务；如果后台启动被阻止，正常打开目标 Edge 配置文件再等待。
- 扩展被禁用时，请在 Edge 中手动确认启用。脚本不会强行绕过确认。
- 本目录的 `config.json`、`login.log`、`Extension/login-request.json` 是安装后生成的本机状态，提交 GitHub 或反馈问题时不要附带。

验证通过代表浏览器默认搜索请求指向 Google，不代表 Google 页面或网络可达。测试会创建并关闭一个后台标签页，随机测试词可能出现在正常搜索历史中。每个新请求首次失败后只尝试重载自身一次。

当前版本只支持单个配置文件及一个固定任务名。真实改为其他引擎后的自动恢复、其他扩展竞争尚未完成回归。手动按钮失败重载后可能转为处理登录请求；需要可追踪的新请求时使用 `Verify.cmd`。

## 卸载

先运行原目录里的 `Uninstall.cmd`，再从 Edge 扩展管理中手动移除“Google 搜索守护（个人版）”。脚本会保留文件，完成卸载后可以自行删除。

扩展 ID 固定为 `fnbpglchnbbhcmjcoapbafejooijecah`；不要重新生成 `manifest.json` 内的公钥或单独改写 `extension-id.txt`。
